Morning Dashboard

A private tool that gathers one person’s own schedule, mail and tasks into a single page.

HomePrivacy PolicyTerms of Service

What it is

Morning Dashboard is a personal productivity tool built and run by one individual for his own use. It runs on his own Windows computer. Once an hour during the working day it collects his schedule, the mail waiting on him, and his open tasks, scores them for priority, and writes the result to a single HTML page he opens in a browser.

It is not a product, not a service, and not offered to anyone else. There is no sign-up, no hosted component and no other user. It is published here only because Google requires an application using its APIs to have a home page, a privacy policy and terms of service at public addresses.

What it connects to

SourceWhat it readsAccess

Open-Meteo, weather.govForecast and alertsPublic, no account

Read-only, by design. The Google access this application requests cannot send, delete, modify or label mail, and cannot create or change calendar events. It can only read. That limit is enforced by Google, not by a promise made here.

Where the data goes

Nowhere. Everything collected is written to files on the one computer that collects it. There is no server, no database, no cloud component, no analytics and no third party. Nothing is transmitted anywhere except back to the Google, Microsoft and Asana APIs the data came from.
