Summary

Morning Dashboard is a personal tool with one user: its author. It reads his own Google account, read-only, on his own computer. It stores what it reads on that computer and sends it nowhere. There are no other users, no servers and no third parties.

Who this covers

This application is operated by an individual for personal use. It is not a company, not a service, and has no customers. If you have arrived here from a Google consent screen, you are the author — nobody else is able to use this application.

What is accessed

ScopeWhy
gmail.readonlyTo list recent messages and score which ones are waiting on a reply. Sender, subject, date, snippet and read state are used.
calendar.readonlyTo read today’s and tomorrow’s events so the day’s schedule and remaining free time can be shown.

Both scopes are read-only. The application cannot send, delete, modify, archive or label mail, and cannot create, change or delete calendar events.

Where data is stored

  • Collected data is written to files on a single Windows computer, in the user’s own local profile.
  • Credentials are encrypted with the Windows Data Protection API, tied to that one Windows account on that one machine. Copied elsewhere, they do not decrypt.
  • The rendered page is a local HTML file. Yesterday’s copy is kept for 30 days and then deleted.
  • No data is uploaded, synchronised to a server, backed up off the machine, or shared with anyone.

What is never done

  • No data is sold, rented, traded or transferred to any third party, under any circumstance.
  • No data is used for advertising, profiling, marketing or resale.
  • No data is used to train, fine-tune or evaluate any machine learning or artificial intelligence model.
  • No analytics, telemetry, crash reporting or usage tracking of any kind is collected or transmitted.
  • No human other than the account owner reads the data.

Google API Services — Limited Use disclosure

This application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through Google APIs is used solely to provide and improve the single user-facing feature described above — a private summary page for the account owner. It is not transferred to any third party, is not used for advertising, is not used to train generalised artificial intelligence or machine learning models, and is not read by any human other than the account owner.

Retention and deletion

Collected data is overwritten on each run, roughly hourly. Archived copies of the rendered page are deleted automatically after 30 days. To erase everything, the user deletes the application’s folder and its local data folder; nothing persists anywhere else.

Revoking access

Access can be withdrawn at any time from Google Account › Third-party apps & services. Revoking it immediately and permanently ends this application’s ability to read anything.

Changes

If this policy changes, the effective date above changes with it. Because there is one user, and that user is the author, no separate notification mechanism exists.
